# Social preview and LinkedIn brand assets

The reviewed [portfolio preview](../public/social/portfolio-og-2026-10-24.png) is served at
`/social/portfolio-og-2026-10-24.png`. It is a 1200 × 627 px PNG, preserved byte-for-byte
from the approved 2026-10-24 design, and it is the Open Graph and Twitter image for every
English and Spanish route through [shared metadata](../src/views/metadata.ts). The same file
is ready for manual LinkedIn Featured uploads.

It shows the three-role headline (AI Engineer, Software Engineer, Product Engineer), the
positioning line "I build LLM agents for production, and the evals that show they work" and
the domain, with the approved portrait in the portfolio's fonts and cyan palette. The copy
is English on both locales; a Spanish variant would be a new reviewed asset.

This is a deliberately dated branding snapshot. Future identity or copy changes need a
newly reviewed image under a new dated name, and the metadata must point to it; do not
edit a published file in place. The 2026-10-13 thumbnail and the generated per-locale Open
Graph routes it accompanied were retired with this release. A 2× original, the LinkedIn
cover and earlier upload assets stay outside this repository. No LinkedIn account settings
are automated.
