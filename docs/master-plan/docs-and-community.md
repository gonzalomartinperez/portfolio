## 3. Docs system

| Item | Standard |
|---|---|
| Structure | Diataxis under `docs/`: `tutorials/`, `how-to/`, `reference/`, `explanation/`; GitHub-rendered Markdown, no generator; mapping in [file-moves.md](file-moves.md) |
| Diagrams | Mermaid C4 levels 1-2 in README and `docs/architecture/`; existing light and dark SVGs move to `docs/architecture/diagrams/` and are regenerated from the `.mmd` sources |
| ADRs | MADR 4 in `docs/decisions/NNNN-title.md` with a Confirmation section; the list is in [target-state.md](target-state.md) section 8; ADR paths stay stable |
| Specs | `docs/specs/` and `docs/verification/` keep the spec-driven record; `template.md` is the entry (small fixes keep the spec in the issue) |
| Changelog | Keep a Changelog plus SemVer by release-please; `docs/release-history.md` seeded once |
| Code docs | TSDoc on exports |
| Docs CI | lychee (PR and weekly), markdownlint-cli2, Vale on English prose, cspell (en-US and es-419 for content), skills validator, README heading check; docs-only PRs run only these |
| No volatile facts | counts, versions and URLs are generated or linked, not hand-written |
| Agent docs | `AGENTS.md` <= 200 lines (commands, layout of non-obvious things, deviations, boundaries, skills, docs map); `CLAUDE.md` is `@AGENTS.md` plus Claude-only notes; the nested Next.js agent block stays (written by `next dev`) |
| Owner decisions | `docs/master-plan/owner-decisions.md` and `owner-decisions-existing.md` (byte-identical) are linked from `AGENTS.md` |
